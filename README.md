# EHSAN AI

یک وب‌اپلیکیشن فارسی، راست‌چین و قابل توسعه برای دستیار هوش مصنوعی چندرسانه‌ای.

## اجرا

نیازمندی: Node.js 20+

```bash
npm install
cp .env.example server/.env
# سپس OPENAI_API_KEY را در server/.env قرار دهید
npm run dev
```

فرانت‌اند Vite روی پورت 5173 و بک‌اند روی 8000 اجرا می‌شوند. برای استفاده از API از پروکسی Vite در نسخه توسعه یا reverse proxy در استقرار استفاده کنید.

## ساختار

- `client/`: رابط React/Vite، RTL، تاریخچه محلی، تم روشن/تاریک، فایل و میکروفون مرورگر.
- `server/`: Express، نگهداری امن کلید API، پردازش PDF/DOCX/TXT/CSV/کد، تصویر و اتصال به Responses API.

## امکانات واقعی

- چت واقعی از طریق OpenAI Responses API در صورت تنظیم `OPENAI_API_KEY`.
- جست‌وجوی وب از طریق ابزار وب مدل با کلید `جست‌وجوی وب`.
- استخراج متن PDF با pdf-parse و DOCX با mammoth.
- ارسال تصویر به مدل بینایی در صورت پشتیبانی مدل انتخاب‌شده.
- گفتار به متن پایه با Web Speech API مرورگر و خواندن پاسخ با SpeechSynthesis.
- محدودیت فایل و حذف فایل موقت پس از پردازش.
- کلید API هرگز در کد فرانت‌اند قرار نمی‌گیرد.

## استقرار

برای production، `npm run build` را اجرا کنید و پوشه `client/dist` را با یک وب‌سرور سرو کنید؛ مسیر `/api` را به سرور Express reverse-proxy کنید. در محیط استقرار، `OPENAI_API_KEY` را در Secret/Environment Variables سرویس میزبانی تنظیم کنید.

## نکته هزینه

استفاده از APIهای مدل و ابزارهای وب ممکن است هزینه داشته باشد و رایگان نامحدود نیست. قیمت‌ها را قبل از انتشار عمومی از صفحه قیمت رسمی ارائه‌دهنده بررسی کنید.
