# EHSAN AI

یک وب‌اپلیکیشن فارسی، راست‌چین و قابل توسعه برای دستیار هوش مصنوعی چندرسانه‌ای.

## اجرا

نیازمندی: Node.js 20+

```bash
npm install
cp .env.example server/.env
```

سپس مقدار `OPENAI_API_KEY` را در فایل `server/.env` قرار دهید و اجرا کنید:

```bash
npm run dev
```

فرانت‌اند Vite روی پورت 5173 و بک‌اند روی پورت 8000 اجرا می‌شوند.

## ساختار

- `client/`: رابط React/Vite، راست‌چین، تاریخچه محلی، تم روشن/تاریک و امکانات فایل و میکروفون مرورگر.
- `server/`: Express، پردازش فایل و اتصال به API هوش مصنوعی.

## امکانات

- چت هوش مصنوعی از طریق OpenAI Responses API با تنظیم کلید API.
- جست‌وجوی وب در صورت پشتیبانی و تنظیمات لازم.
- استخراج متن فایل‌های PDF و DOCX.
- پشتیبانی از تصویر در صورت سازگاری مدل انتخاب‌شده.
- گفتار به متن و خواندن پاسخ با قابلیت‌های مرورگر.
- نگهداری کلید API در بک‌اند، نه در کد فرانت‌اند.

## استقرار

برای انتشار عمومی، فرانت‌اند و بک‌اند باید روی سرویس‌های میزبانی مستقر شوند و مسیر `/api` به سرور Express متصل شود. کلید API را فقط در بخش متغیرهای محیطی امن سرویس میزبانی قرار دهید.

## نکته هزینه

استفاده از API هوش مصنوعی ممکن است هزینه داشته باشد و لزوماً رایگان یا نامحدود نیست.
